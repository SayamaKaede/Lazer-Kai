# Lazer-Kai

osu! および ppy とは関係ありません。不具合が発生しても osu! 側に問い合わせないでください。

[osu!lazer](https://github.com/ppy/osu) のフォークです。**マッピングを楽にすること**だけを基準に、エディターへ機能を追加しています。

ポータブル形式で、譜面・設定・スコアはフォルダの中に保存されます。**本家の osu!lazer とは別のデータを使うので、どちらも両立して使用できます。**

## 主な追加機能

**エディターでのMod表示**
テストプレイのModを、エディター画面にそのまま表示できます。HD・FL・DTなどを付けたときの見え方を、テストプレイに入らずに確認できます。

**STATUS 欄**
SR・PP・スコア・SV・音量・コンボ数・ドレインタイムなどを、再生位置に合わせて表示します。表示する項目は選択できます。

**難易度グラフ**
譜面のどこが難しいかを1本の曲線で表示します。クリックするとその位置へ移動します。

**タイムラインの表示形式**
Stable に近い形式を選択できます。ノーツが下端に揃い、SVと音量はその上に並びます。

**アンスナップの検知**
RCと同じ基準（2msより大きいもの）で、タイムラインに印が表示されます。

**.osu のドラッグ&ドロップ**
エディターで譜面を開いた状態で .osu ファイルをドロップすると、そのセットの難易度として取り込めます。

**Mapping Tools との連携**
今エディターで開いている譜面を、そのまま Mapping Tools で開けます。

このほか、コンボカラーの編集画面、スライダーの連打変換、グリッドの初期値設定などがあります。

## インストール

1. [Releases](https://github.com/SayamaKaede/Lazer-Kai-Releases/releases) から `LazerKai-win-Portable.zip` をダウンロードする
2. 好きな場所に解凍・展開する
3. フォルダの中の **`Lazer-Kai.exe`** を実行する

譜面・設定・スコアは、このフォルダの中に保存されます。`current` フォルダは更新のたびに入れ替わるので、**中身を触らないでください。**

## 更新

**自動で更新されます。** 新しい版が公開されると、起動中にダウンロードされ、通知をクリックして再起動すると適用されます。譜面・設定・スコアはそのまま残ります。

手動での上書きは不要です。

## 再配布について

配布は [Releases](https://github.com/SayamaKaede/Lazer-Kai-Releases/releases) だけで行っています。**転載や再配布はしないでください。**

古い版が出回ると、修正済みの不具合の報告が届いたり、更新の通知が表示されない状態の人が出たりします。人に渡すときは、このページを教えてください。
